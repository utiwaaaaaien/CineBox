# 安全报告 / Security reports

请勿在公开 Issue、PR、截图或日志中提交密钥、真实联系方式或未获授权的项目资料。发现安全问题时，请使用仓库 Security 页中的私密漏洞报告入口（若维护者已启用）；如入口不可用，先提交不含复现细节或敏感数据的 Issue，请求维护者提供私密沟通方式。

Do not include credentials, personal contact details, or unauthorized project information in public issues, pull requests, screenshots, or logs. Use private vulnerability reporting on the repository's Security page if enabled. If it is unavailable, open an issue without exploit details or sensitive data and request a private reporting channel.

当前 V6 将用户项目保存到当前站点来源的浏览器存储。公开仓库和内置历史记录可被任何人读取。浏览器存储不是加密的云端备份；请在清除网站数据或切换域名前导出备份。

V6 stores user projects in browser storage for the current site origin. The public repository and its built-in historical records are publicly readable. Browser storage is not an encrypted cloud backup; export a backup before clearing site data or changing origins.
