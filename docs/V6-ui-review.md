# V6 前端审查与发布验证

日期：2026-10-18。范围：项目管理、历史项目、项目信息、总器材库、当前器材单、预览与换机弹窗，以及全局导航、主题和键盘操作。

## 设计方向与验收

参考 [Apple macOS 27](https://www.apple.com/os/macos/) 对可读性和对比度的调整，以及 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 对导航层、内容层的区分。保留 CineBox 的系统字体、蓝色操作强调、深浅色主题及轻量半透明导航；内容卡片使用实色，按操作任务组织信息。

历史卡片按项目名、三列数据、操作区排列：固定“器材 / 机位 / 型号”，主型号单独显示，移除卡片中的拍摄天数。标题与数据之间 20px，数据列间 16px，操作区间 8px；型号获得更宽列并允许换行。清单没有主机位字段，因此优先显示清单中首个常规摄影机，只有辅助摄影机时回退到首个摄影机；缺少型号显示破折号。

侧栏导航与当前项目卡片共用容器宽度，桌面 1280px 下均为 x=12px、宽 215px。手机改为三项底部导航，历史卡片单列，768px 下双列。先完成实现，再统一检查桌面与手机；本轮观察到的问题集中修复后仅做一次确认，不继续扩大视觉调整。
