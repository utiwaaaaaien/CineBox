# CineBox 摄影指导决策工作台升级设计

## 目标

把 CineBox 从“按项目类型生成器材单”升级为“从创作意图推导技术方案，再落到可执行器材单”的摄影指导工作台。新版保留现有克制、专业的视觉语言和本地优先的数据模式，重点降低错误确定性、兼容风险和海量器材带来的选择压力。

## 方案比较

### A. 只扩充问卷

增加更多创作与技术字段，但继续使用现有推荐、检查和替换逻辑。实施快，但会让用户填写更多信息，却无法解决卡口不兼容、替换后系统失配以及“6/6 完整”的错误确定性。

### B. 决策链与兼容层同步升级（采用）

把工作流重排为“创作命题 → 影像策略 → 拍摄参数 → 器材方案 → 兼容审阅”，并让新增字段真正参与机型、镜头、灯光、存储与供电计算。增加系统状态、兼容检查和联动替换，同时保持当前单页架构与本地存储。它能直接提升专业可信度，又不引入账户、云数据库和多人协作的额外复杂度。

### C. 全面重构为云端协作平台

加入账户、项目共享、租赁公司报价与审批流。长期价值高，但会扩大隐私、权限和数据维护范围，不适合作为本轮优化的前置条件。

## 信息架构

项目问卷调整为五个区块：

1. 项目基础：项目类型、日期、规模、机位和负责人。
2. 摄影创作简报：叙事视点、画幅比例、影调、反差、运动原则和场景条件。
3. 摄影系统：机身偏好、镜头语言、监看与灯光规模。
4. 拍摄参数：基础帧率、升格帧率、分辨率、记录规格、拍摄比、每日工时和供电条件。
5. 备注：明确标注“不参与自动推荐，只进入项目与导出备注”。

首屏仍保留历史项目与仅按问卷两种模式，但将百分比改称“匹配分”，并显示评分依据，避免把规则分数误解成统计置信度。

## 推荐与兼容逻辑

- 画幅、影调、场景和参数参与机身、镜头与灯光推荐。
- 记录规格、拍摄比、帧率、工时和拍摄天数共同决定存储与电池周转提示。
- 高帧率不再只切换机身，还会补充光量、存储和散热检查。
- 横竖双版本增加开放门、安全框与双构图监看提示。
- 使用现有器材属性中的卡口和滤镜尺寸，加入机身—镜头卡口检查；不兼容时生成明确的转接与支撑待确认项。
- ND、CPL、Clear 从“一律必需”改为按日外、反光材质与环境风险分级。
- 系统状态改为“已确认 / 系统推荐 / 待确认 / 手动添加”，通过检查时显示“基础链路已覆盖”，不再声称绝对完整。

## 替换、分类配置与导出

- 更换机身或镜头时提供“联动重算系统”和“只替换此项”两种操作。默认联动重算，保留用户手动添加的器材与同型号备注。
- 分类配置先显示与项目、当前机身和预算强度最相关的候选，支持切换到全部同类；每张卡补充匹配理由与配置强度。
- Excel 增加“系统审阅”工作表，列出推荐依据、待确认项、兼容风险和创作/技术参数。
- 项目备份增加“导入并合并”，让导出的 JSON 真正可恢复。

## 视觉与无障碍

- 保留现有浅色工作台、绿色强调色和侧栏结构。
- 辅助文字最低 11px，重要说明与推荐理由最低 12px；移动端导航最低 10px。
- 所有新增控件使用明确标签、键盘焦点和状态文本。
- 空状态、导入错误、无兼容候选和联动重算结果均提供可理解的反馈。

## 验收标准

- 用户能先表达创作意图，再选择器材，而不是从品牌开始。
- 高帧率、横竖双版本、场景条件和拍摄参数会改变推荐或检查结果。
- 不兼容机身与镜头组合会出现明确警告和转接建议。
- 更换机身后可联动重算镜头、供电、存储、监看与承托。
- “基础链路已覆盖”与“待确认项”不会把泛化占位器材误报为完全确认。
- 分类配置默认不再一次暴露全部 46 台摄影机或 818 条镜头。
- Excel 同时包含器材单和系统审阅。
- JSON 备份可以重新导入并合并。
- 桌面与移动端核心流程可完成，现有测试和新增测试全部通过。
