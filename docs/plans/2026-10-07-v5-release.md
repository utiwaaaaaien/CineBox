# V5 发布核验

用户要求继续搜索待核验器材，包括别名和昵称；无法确认具体产品、规格冲突或过于模糊而不适合选材的条目不进入新建器材库。审核档案及旧项目引用保留。

1. 已完成厂商产品系列和型号资料复核，记录官方来源、规格冲突及检索线索。品牌首页不作为具体型号的依据。
2. 按用户澄清重新整理：规格小冲突按官方资料纠正，具体型号、镜头组、滤镜及用途明确的附件继续可选。当前 2,001 条可选、4 条无法形成明确选材描述的记录移出新入口，88 条重复合并。可选状态与官方核验状态分开，旧 ID 可解析。
3. 已实现图标、两项名称字段、系列和加入按钮；首项中文优先，次项英文，不附其他名称说明。
4. 已通过目录一致性、65 项回归测试及生产构建，覆盖规格纠正、模糊名称排除、具体库存保留和旧项目迁移。沿用现有网站和访问范围发布，最终结果以部署工具确认的成功状态为准。
