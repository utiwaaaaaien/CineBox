# CineBox Excel 导出设计

## 目标

让“导出 Excel”成为可完成的交付动作：点击后生成真实 `.xlsx` 文件并打开浏览器的另存为流程，让用户选择文件名和保存位置。工作簿视觉结构参考《实习丘比特》和《断片》摄影器材单，而不是通用数据表。

## 参考格式结论

两份历史器材单都采用以下阅读顺序：

1. 顶部黑色 `Camera Equipment List` 标题带。
2. 摄影指导、联系电话和拍摄时间信息行。
3. 灰色字段表头。
4. 按摄影机、镜头、滤镜、摄影机附件、监看、移动器材等大类分段。
5. 每个大类先显示中英双语分段标题，器材明细左侧保留灰色分类栏。
6. 明细核心字段为设备名称、数量、单位和备注。
7. 底部保留备注行。

《断片》额外包含租借方和器材原值，但 CineBox 当前没有这两个可靠字段，因此本次不生成空的伪数据列。保留五列结构，更接近《实习丘比特》的可直接发单版本。

## 方案选择

采用浏览器端即时生成，并优先调用浏览器 File System Access 保存选择器：

- 优点：不上传项目数据；在生成前打开正式另存为流程；保持现有离线项目架构；无需新增服务端文件存储。
- 兼容处理：用户取消保存时不显示成功；导出中禁止重复点击；生成失败显示明确提示。
- 兼容处理：不支持保存选择器的浏览器退回标准下载，并提示由浏览器下载设置决定位置。
- 不采用服务端生成下载，因为会增加上传项目数据和临时文件管理，且没有必要。

## 工作簿结构

- 文件名：`项目名-摄影器材单.xlsx`，自动清理文件系统非法字符。
- 工作表：`器材单`。
- 冻结顶部四行，隐藏默认网格线，横向页面。
- 标题行跨五列。
- 信息行包含摄影指导、联系方式、拍摄日期范围和项目类型。
- 日期按拍摄天数自动换算结束日期。
- 大类标题使用中英双语标签。
- 数量写为数字类型，联系方式写为文本类型，避免 Excel 自动改写。
- 备注为空时保持空白，不填造数据。

## 验证

- 单元测试覆盖日期范围、非法文件名、分类合并、列结构和新版样式字段。
- 生成代表性 `.xlsx`，重新读取并渲染，检查标题、合并、分组、行列宽度与中文显示。
- 完整构建与现有测试通过后发布。
