# CineBox UI/UX 优化设计

## 目标

把 CineBox 从“器材数据库界面”进一步调整为“摄影指导完成项目配置的工作流”。本轮不重做视觉品牌，保留现有克制、专业的浅色工作台风格，集中减少完成核心任务所需的滚动、判断和返回成本。

## 体验结论

- 默认进入器材库会放大 1,947 条数据带来的选择压力，核心路径“问卷 → 推荐 → 调整 → 导出”不够突出。
- 器材库中的系列卡片默认展开，占据大量首屏空间，普通单件搜索被向下推迟。
- 问卷内容较长，提交操作只出现在末尾；用户修改上方选项时缺少持续可见的下一步。
- 器材单在检查全部通过时仍展示大型检查卡与重复提示，真正需要审阅的器材行出现在较下方。
- 库外器材表单默认展开，属于低频功能，却在每次审阅中持续占用空间。
- 更换面板一次展示大量同类别器材，虽然已排序，但缺少推荐范围和匹配理由。
- 390px 移动端主导航会离开视野，长器材单中返回问卷、分类配置或导出不够方便。
- 多处 8–9px 辅助文字和浅灰颜色降低可读性。

## 方案选择

采用“工作流优先的渐进优化”。相比全面视觉重构，它对现有用户认知影响更小；相比只调整颜色和间距，它直接改善任务完成效率。

## 具体设计

1. 新会话默认进入项目问卷，侧栏按“项目管理、项目问卷、分类配置、当前器材单、器材库”排列。
2. 器材系列默认折叠；选择镜头分类、品牌或输入搜索后自动展开。
3. 问卷提交区使用底部粘性行动条，保持当前推荐摘要与生成按钮可见。
4. 器材单检查通过时压缩为单行状态；只有存在遗漏时才展开检查面板。无问题时不再重复显示 DOP 卡片。
5. 增加“修改问卷”入口；库外器材改为按需展开。
6. 更换面板提供“优先推荐、同品牌、全部同类”范围，并显示同子类别、同品牌或同大类的匹配理由；支持 Escape 关闭并锁定背景滚动。
7. 移动端将主导航固定在底部，并为页面保留安全区域。
8. 加深辅助文字颜色，提高关键说明、表单标签和推荐理由字号。

## 验收标准

- 新用户能直接看到两种推荐模式并开始问卷。
- 从问卷顶部滚动时，生成操作持续可达。
- 检查通过的器材单首屏能更快看到器材分类，而非多个状态面板。
- 更换器材默认只显示高相关候选，可切换到同品牌或全部。
- 移动端任意滚动位置均可访问五个主要功能。
- 所有已有推荐、替换、系统检查、导出与本地保存行为保持可用。
