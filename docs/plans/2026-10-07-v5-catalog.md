# V5 器材库整理

1. 冻结 V4.1 库存快照，检查名称、误归类和误合并。输出原始条目追溯记录。
2. 建立官方品牌与产品命名资料。中文官网、官方中文说明书优先；无法核验则保留待核验状态，禁止自行翻译品牌或推断型号。
3. 全库拆分品牌中文名、品牌英文名、系列、型号和规格；统一名称由字段生成。焦段、卡口、代际、光圈、尺寸、密度及改装配置均参与身份判断。
4. 恢复已误合并的规格，合并可确认的同名同规格记录，生成旧 ID 映射和逐条审计记录。
5. 接入器材目录、品牌筛选、系列、历史项目和器材单；验证备份恢复、搜索、推荐和 Excel 导出。

验收：每条记录有核验状态；名称符合统一格式；任何合并均可追溯；旧项目引用仍可解析；不同规格不会在系列视图中被隐藏；构建、受影响的功能测试和界面检查通过。

用户已确认：不同焦段、卡口、代际、光圈、滤镜尺寸和密度分别保留；只合并同型号同规格；官网无法确认的条目标为待核验。
