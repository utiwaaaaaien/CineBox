# V5.5 前端调优验证

2026-10-07。按 `.impeccable/critique/2026-10-07T11-52-12Z__app-page-tsx.md` 调整四主界面，采用桌面紧凑、手机保留触控空间的方向。

## 调整结果

- 页头由 76px 收到 64px；外观切换收进一个按钮，使用实体弹出层。
- 桌面常规工具控件 36px，手机主要按钮至少 44px；品牌块 56px。品牌英文和项目字段标签为 13px。
- 项目名称 20px，历史名称 18px，器材名称 15px；保留系统字体。减少卡内分隔线、分类及品牌按钮的默认框线。
- 项目卡保留宽度，首张由约 478×332px 变为 478×305px。显示当前项目标识和打开入口；编辑直接可用，复制、归档、删除放进更多。
- 备份、更多和外观共用可关闭的 disclosure；选择完成、点击外部或 Escape 可关闭，Escape 和外观选择后返回触发控件焦点。
- 手机用品类选择器展示全部十项，不再依赖横向滑动发现后续品类。
- 选择器材移除重复的项目介绍，已确认的基本信息摘要显示项目名称及拍摄参数；系列补充改为轻量展开栏。日期和数字输入不再因辅助说明产生不同高度。
- 当前项目配套检查保留功能，移除装饰英文标签，数字排版使用统一系统字型。

手机品牌折叠 4 项、展开 12 项；选择不在前四项中的佳能后，收起仍能看见当前品牌。品类选择器可直接进入灯光器材等后续类别。桌面品牌按六列、两排预览。

四界面在 1280×720 和 390×844 浏览器中检查。额外检查 320px 窄屏、820px 中间宽度及 1920px 宽屏；没有页面横向溢出。320px 下拍摄日期换行显示完整内容。1920px 下卡片宽约 387px，长项目名允许换行。

外观菜单鼠标选择及键盘方向键切换均正常。更多菜单可展示完整操作，点击外部与 Escape 关闭正常。历史预览 Escape 关闭后，焦点返回预览按钮。基本信息表单日期、数字输入均约 46px 高。浅色实测选中品牌文字对比度 5.28:1、品牌英文 5.08:1、器材英文 5.68:1；深色视觉检查正常。

未修改器材目录身份、项目数量或备注。检查使用浏览器本地既有验收项目，没有导入或删除用户数据。证据截图的项目名称仅属于本地验收数据。
