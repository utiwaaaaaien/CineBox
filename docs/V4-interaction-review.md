# CineBox V4 交互审查与改动

审查日期：2026-10-07。目标使用者为摄影指导；主要任务是快速完成器材单，并明确遗漏、兼容性和待确认项。审查依据为本次实际页面、现有推荐逻辑与 Apple 官方资料，未进行真实剧组的计时用户测试。

## 设计依据

- [macOS 27 官方介绍](https://www.apple.com/os/macos/)：阅读清晰度、工具栏一致性和内容层级。
- [WWDC26 Design guide](https://developer.apple.com/wwdc26/guides/design/)：直观搜索、明确命名及设计原则。
- [HIG Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：按需展开，减少同时呈现的内容与选择。
- [HIG Entering data](https://developer.apple.com/design/human-interface-guidelines/entering-data)：减少易错输入，明确需要的数据。
- [HIG Undo and redo](https://developer.apple.com/design/human-interface-guidelines/undo-and-redo)：说明撤销的具体操作，支持 Command-Z 和 Shift-Command-Z。

这些原则用于网页交互设计；本网站使用网页控件，并非原生 macOS 应用。

## 本次发现与处理

| 当前证据 | 问题与影响 | V4 改动 |
| --- | --- | --- |
| 01 问卷，44 个控件，桌面内容高度约 2911px | 项目资料、创作意图、周转参数和重复摘要同时展开；起始步骤过长 | 三组核心需求；创作和联络资料按需展开，并在折叠标题显示当前值。初始显示 31 个控件，桌面高度约 1527px |
| 01 问卷：画面方向、成片画幅、竖屏复选框 | 多个入口能表达冲突状态 | 一个交付画幅控件，同步画幅与方向；9:16 和横竖双版本均可选择 |
| 01 问卷：高帧率复选框与最高升格帧率 | 重复输入，修改参数容易与选项脱节 | 单一升格帧率入口，自动同步推荐所需的高帧率标记 |
| 02 分类选材，1/9 类与上一类、下一类 | 导航暗示必须依次完成九类；与器材库重复 | 合并为一个选材入口。搜索型号、自由切换类别；项目优先和器材库顺序都包含全部器材 |
| 器材库按钮：加入后变成 +1；整组加入后变成移除整组 | 重复点击加量或批量删除已经确认的项目 | 已加入状态禁用；系列只补入未选项，保留已有数量、备注与状态；数量集中在清单修改 |
| 03 清单：配套 6/6，但仍有 4 条待确认 | 绿色覆盖提示容易被理解为器材已确认 | 待确认数量直接显示，存在待确认项时使用提示色；提供待确认筛选和清单搜索 |
| 换机联动立即重算 | 多项改变难以预知 | 先预览新增、移除、调整及状态，再应用；替换器材标为待确认 |
| 清单增删、换机、补齐和生成无法恢复 | 误操作成本较高 | 当前打开期间按项目保存最近 30 次修改，可撤销/重做；连续同字段修改合并为一次撤销 |
| 需求改变后旧清单继续显示 | 用户可能误认为清单已按新参数更新 | 保留“需求已修改”提示至重新生成，恢复项目后仍显示；导出的审查摘要保留此提示 |
| 手机页头与长介绍占用首屏 | 关键操作和搜索结果出现较晚 | 取消重复清单按钮和大型介绍区；搜索优先，手机提交区只保留主要操作 |

## 关键行为边界

默认参数继续参与推荐；存储、工作时长、拍摄比和现场供电保持直接可见。未确定的配套不自动视为已确认，发单前仍应完成机型与租赁方的实际核对。推荐规则提供站内检查，不能证明实物兼容性或器材库存。

历史复用、历史单本地解析与确认、库外器材、项目复制/归档/备份、Excel 完整清单和审查表继续可用。筛选只影响屏幕显示，不删减导出内容。生成与换机保留已编辑的数量、备注和人工项目；联动预览让新增配套可检查。

撤销记录属于当前页面会话，刷新页面后不保留；项目和器材单仍自动保存于当前设备。原有项目备份数据格式兼容，新增需求提醒随备份保存。
