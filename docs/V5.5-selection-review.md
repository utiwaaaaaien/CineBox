# CineBox V5.5 选材流程核验

网站版本为 V5.5，器材目录保留 V5.1 的 2,084 个可选条目和完整旧身份档案。

- 默认首页为项目管理；历史复用、直接选材为独立入口，当前器材单保留编辑与导出。
- 基本信息包括项目名称、类型、分类、拍摄开始日期/周期、天数、单机/双机/多机位、分辨率、画幅比、基础和升格帧率；联络和备注折叠。
- 移除问卷推荐入口、创作风格和预算字段、偏好排序与历史匹配分。旧偏好可随备份保留，但不会参与当前选材、兼容检查或 Excel 项目摘要。
- 品类下提供所含品牌菜单；切换品类重置品牌，手机品牌菜单横向滚动；型号、英文、旧称搜索可用。
- 器材行、系列及替换候选使用文字品牌，移除品牌缩略图。
- 已保存项目可复制为新项目，保留器材数量、备注和自定义项。历史底稿按明确选择复用，旧身份可恢复，同一身份的旧 ID 数量合并；已有人工修改继续保留。
- 配套检查依据机型、已选器材和可见规格；通过用户按钮补入的配套标为待确认。拍摄规格更改后显示人工复核提示。

验证：`pnpm run catalog:check`、生产构建、80 项回归与 `pnpm run lint` 通过。新增覆盖品类品牌范围、旧称检索、历史数量与旧 ID、旧偏好隔离、Excel 基本信息、基本信息保存恢复。

浏览器交互验证：新建项目和保存基本信息、拍摄周期显示、品类/品牌切换、机身/镜头加入、数量备注修改、撤销重做、刷新恢复默认项目管理、保存项目复用为新项目、明确选择《断片》底稿与保留人工调整。检查了桌面及 390px 手机视口；手机无页面横向溢出，器材行无图片。

截图：`docs/verification/v5.5-selection-desktop.jpg` 与 `docs/verification/v5.5-selection-mobile.jpg`。

补充检查：独立 `tsc --noEmit` 仍受到此前原始库存大数组的复杂联合类型和缺失 Cloudflare Workers 类型声明影响；本次新增文件未报告类型错误。PDF 导入的资源清理已改为由 loadingTask 调用 destroy，以适配当前 PDF.js API。生产构建与运行测试正常。
