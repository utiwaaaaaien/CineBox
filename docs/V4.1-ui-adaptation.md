# CineBox V4.1 · macOS 27 视觉适配

目标：将现有摄影指导工作台的导航、工具栏、表单和器材清单统一为参考 macOS 27 的网页界面。

## 设计依据

- [Apple macOS 27 Golden Gate](https://www.apple.com/os/macos/)：更清晰的 Liquid Glass、统一工具栏、贯通侧栏。
- [Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：玻璃用于导航和控件层，内容保持清晰；避免在内容中泛用玻璃。
- [Adopting Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/adopting-liquid-glass)：优先保持标准控件、功能分组和可读性。

本次是网页视觉适配，使用 CSS 材质与系统字体，未使用 AppKit 的原生材质渲染。

## 实施

- 通过独立 `app/macos.css` 统一视觉变量与响应式规则，覆盖旧样式。
- 侧栏采用轻量列表与独立项目摘要；工具栏和固定操作区采用玻璃材质，器材内容采用实体表面。
- 统一按钮、选择器、输入框、分段控件和表格层级；以蓝色标识选择与主要动作。
- 搜索、撤销、重做、关闭和新增使用统一线宽的 SVG 图标，保留可访问名称与快捷键提示。
- 手机使用悬浮底部导航，问卷操作条与导航分离；窄屏工具栏自动换行。
- 明暗模式分别配置文本与背景；减少透明度、增强对比度和不支持背景模糊时提供实体表面回退；继承减少动态效果设置。

## 验证

在浏览器模拟的 1440、820、390 和 320 像素宽度检查项目管理、需求表单、器材库和器材单；明暗主题均检查。主要操作控件最小高度 44 像素，手机工具栏图标为 44×44 像素。问卷操作条与底部导航留有间距。

发布前执行生产构建、已有功能回归测试、修改文件的静态检查和视觉检查。实体设备的系统材质表现不属于本次模拟检查结果。
