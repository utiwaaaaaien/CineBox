# V5.5 UI 精简验收

## 已完成

- 主导航仅有项目管理、历史项目、选择器材、总器材库。当前项目统一进入清单编辑、数量和备注、配套核对、Excel 导出。移动端将当前项目入口放在工具栏。
- 项目卡片在 1280 px 视口下为约 478 × 332 px，两个辅助入口改为普通文字选项，备份操作收进菜单。
- 历史项目直接显示卡片，每张卡片支持上传替换、预览和复用为新项目。已保存项目的原始数量、备注、自定义器材可预览和复制；上传替换必须经过分析预览确认，已保存清单支持撤销替换。
- 品类下品牌菜单共享于选择器材与总器材库。默认最多两排，展开显示全部，收起仍显示当前选择。按用户确认的品类常用顺序排列，并使用核对过的中文名和英文名。
- 总器材库无需填项目信息即可浏览；未填写基本信息时选用器材会进入当前项目的信息表单，保存后再加入。

## 设计依据

参考 Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与 [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars) 的内容与导航分层、清晰层级原则。网页使用系统字体、克制的颜色和独立玻璃操作层，不宣称通过 Apple 原生系统认证。

菜单译名与目录型号分开维护在 `app/catalog-brands.ts`，保留来源。用户允许可核对的业内通用译名；没有可靠中文译名的品牌保留原文，未虚构译名、器材型号或规格。品牌顺序为快捷选择的编辑顺序，不宣称市场占有率排名。

## 验证

- `pnpm run catalog:check` 通过，2084 个可选条目、2099 个历史可恢复条目。
- `pnpm test`：生产构建及 83 项测试通过。
- `pnpm run lint` 通过。
- Impeccable 机械检查没有发现问题。
- 本地浏览器检查桌面 1280 × 720 与手机 390 × 844；浅色和深色显示、四项导航、放大的卡片、历史预览与复用、上传确认与撤销、品牌展开收起、未确认项目信息的选用流程通过。页面没有横向溢出，器材行没有品牌缩略图，控制台没有错误。
- 本地验收用项目仅保存在本地预览浏览器，不包含在部署源数据中。

完整 TypeScript 检查仍有四项既有问题：旧生成目录的复杂联合类型，以及 Cloudflare `workers` 模块、`Fetcher`、`D1Database` 类型声明。此次改动没有新增类型错误；生产构建及运行检查通过。
