# CineBox V6.6

- **统一选材。** 总器材库和项目选材共用搜索、品类、品牌和系列筛选。切换页面时保留筛选，有当前项目时可加入单件或整个系列、添加自定义器材并预览器材单。
- **审查配套。** 在「当前项目」展开「审查全部配套规则」，逐条查看 15 条规则的触发条件、目标数量、联动方式和当前状态。已有的补齐规则继续按原逻辑运行。
- **清单对齐。** 目录、自定义及补齐器材的名称、数量、单位、备注和操作使用相同布局。
