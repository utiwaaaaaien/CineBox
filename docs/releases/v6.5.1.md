# CineBox V6.5.1

摄影团队可以从项目排期和拍摄规格出发，复用历史配置，挑选器材，核对配套，并导出现场使用的清单。

[在线使用](https://utiwaaaaaien.github.io/CineBox/) · [项目介绍](https://github.com/utiwaaaaaien/CineBox/blob/main/README.md) · [完整版本记录](https://github.com/utiwaaaaaien/CineBox/blob/main/CHANGELOG.md)

## 本次更新

- 品牌和系列选择器默认等高单排，标签完整显示。宽屏并排，窄屏上下排列，展开后可查看全部选项。
- 点击系列筛出相应器材，也可用独立按钮补入整个系列中尚未选中的器材。
- 器材单移除来源文案，收紧分类间距，长型号换行显示。展开和确认反馈遵循系统减少动态效果设置。

## 同步到 GitHub 的 V6.5 改动

- 项目表单直接显示联络与备注，选材页顶部显示项目摘要、已选进度和筛选。
- 配套区展开后只列待补项目和补齐入口。器材单底部支持一键确认、继续选材和导出。
- 可导出 PDF、DOCX、PNG、XLSX 器材单，或导出当前项目的 JSON 备份。

Projects are saved in the current browser. Export and import a JSON backup when moving projects between the Sites deployment and GitHub Pages. The application interface is in Chinese.
