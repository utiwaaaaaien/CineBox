# CineBox V6 交付记录

日期：2026-10-17；界面微调：2026-10-18。

本轮范围是历史项目卡片和总器材库卡片。历史卡片删除“艺人视频 · 历史底稿”等重复备注，项目名先行，器材数、机位数和已有拍摄天数集中显示；底部统一为预览、上传替换、复用操作。

器材卡片按中文品牌、英文品牌、系列、型号及已确认俗称显示名称，第二行改为技术指标，删除右侧系列标签。没有具体型号时，按用户确认采用能归属的系列指标，并在指标悬停说明中注明系列适用范围。系列选择功能及历史项目身份继续使用原目录。

指标与来源按品类保存，生成过程检查稳定 ID、重复指标、来源 URL、适用范围及缺口说明。新增显示名称会参与搜索，旧名称和英文搜索继续有效。显示名校正与规格补录不改变旧项目身份。

用户先确认泛称可以采用系列指标，后于 2026-10-17 确认无法辨识品牌或系列的记录可以保留，先交付；随后要求界面未确定的指标留空，不显示额外提示。因此本版没有声称全库三项指标均已齐全。资料尚不足的卡片显示已经确认的项目，其余留空，缺口原因保留在研究记录中。

界面微调：历史卡片重排为“器材 / 机位 / 型号”三列，型号显示器材单首个常规摄影机的短型号，预览文字左对齐；总器材库每次从导航打开均重置为全部；名称与指标采用不同文字颜色；左侧当前项目使用独立底色，并与导航按钮保持同宽；浏览器与分享标题统一为 CineBox，中文备注为“摄影器材 · 项目工作台”。全面界面检查与修复见 [V6 前端审查](V6-ui-review.md)。

## 验证

- `pnpm test`：生产构建成功，97 项测试全部通过，覆盖目录旧 ID、项目恢复、数量/备注、导出与本轮卡片生成约束。
