# CineBox V6.3 专项器材与分类审查

核对日期：2026-11-15。选材目录从 2,150 项增至 2,306 项：新增 37 项配件、125 项影鼎改装镜头，合并 6 项跨类重复。另复核 5 项铁头旧记录的分类或子类。完整身份目录现有 2,321 项，15 项仅用于兼容历史记录。

配件按功能归入摄影机附件、滤镜和移动器材。铁头 4 项、优篮子 1 项、Falcam 5 项、耐司 21 项、斯莫格 6 项。Falcam 以产品品牌入库，用“优篮子”也可搜到。按套装、零件、滤镜尺寸和密度保留独立身份。来源逐条记录在 [配件数据](../data/catalog/accessories-v6.3.json)，品牌型号核验不代表当地可租。

[影鼎镜头数据](../data/catalog/ying-ding-v6.3.json)对应用户提供的《北京影鼎轻量化改装镜头参数表》18 页。影鼎作为改装目录品牌，原光学系列继续可搜索。来源为供应商参数表。F 值和 T 值依原表，Leica M0.8 光孔单位不足以确定时留空。福伦达 58mm 和 90mm 标注改造中、Takumar 120mm 缺少主要规格，均暂未发布。Mamiya 按主表的实物焦段录入，括号里的 0.71× 转换值不视作额外镜头；Pentax 67 和 645-A 的括号数值也未替代主值。多个可选卡口显示在卡片中，实际安装接口需要确认。影鼎表明确提示 Leica M0.8 这一配置与 ALEXA Mini 有后组干涉。

[分类决定](../data/catalog/classification-v6.3.json)列出旧 ID、合并目标和理由。旧项目恢复沿用既有迁移逻辑：合计数量、保留备注，并将冲突的确认状态设为待确认。其余同名候选见 [审计结果](../data-quality-audit.json) 的 `classificationReview.remainingCandidates`。可能按部门独立配置的铝管和脚手架、不同计量单位的 GF-Primo Dolly 等继续保留。

生成与校验：`pnpm run catalog:build`、`pnpm run catalog:check`、`pnpm run catalog:cards:check`。
